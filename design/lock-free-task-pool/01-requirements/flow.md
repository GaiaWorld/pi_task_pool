# lock-free-task-pool · 业务流程（L1）

```mermaid
flowchart TD
  A[准备串行索引或选择并发档位] --> B{串行索引构造成功或为并发任务}
  B -->|否| P[返回无效索引 不提交任务]
  B -->|是| C{估计等待量少于快速阈值}
  C -->|否| Q[按所属组或档位入队]
  C -->|是| D{执行器空闲且不破坏串行顺序}
  D -->|否| Q
  D -->|是| E[尝试交接任务]
  E -->|接受| X[外部执行]
  E -->|拒绝并退回| Q
  Q --> F[工作线程请求获取]
  F --> G{存在可获取任务}
  G -->|否| N[返回空]
  G -->|是| H[按概率选择并取得任务]
  H --> X
  X --> I[实际完成或正常展开释放句柄]
  I --> J[若为串行任务则允许同组下一任务]
```

| 操作 | 条件 | 结果/后续状态 |
|---|---|---|
| 索引构造 | 串行组不在0至20 | 返回None，不能以该值提交任务 |
| 提交 | 估计等待量达到阈值或不能安全快速交接 | 入所属组/档位等待 |
| 快速交接 | 执行器接受 | 任务交执行器，同组保持占用至完成 |
| 快速交接 | 执行器拒绝 | 收回原任务并入队，恢复可继续调度的状态 |
| 获取 | 有可获取任务 | 返回唯一任务句柄；串行组进入占用 |
| 获取 | 无可获取候选 | 返回空，不等待新任务到达；底层队列取出仍可能等待在途写入 |
| 完成 | 释放句柄 | 串行组解除占用；并发任务不限制同档后续获取 |

## 完备性核对

来源覆盖用户对话、现有方案注释与骨架，未引外部方案。九维：使用者、输入、输出、状态转换、正常路径、异常、并发、生命周期、性能均已核对；未决需求为无。现有位布局与裸指针作为技术素材留至 L7。
