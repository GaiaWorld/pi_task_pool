# 模块清单（L5）

| 模块 | 隐藏的一个易变决定 | 职责 |
|---|---|---|
| 池门面 | 对调用者暴露的提交/获取协议 | 校验、快速路径及普通路径组织 |
| 队列状态 | 存储与串行占用的交接表示 | 21串行、5并发队列；队列长度采样、位布局及压缩提示发布/下调/饱和修复；认领/释放/拒绝守卫；完成句柄 |
| 权重选择 | 快照选择算法 | 只从传入快照计算权重、估算等待量与选择候选，管理随机落点；不修改队列或提示 |
| 执行交接 | 外部执行器接受/拒绝约定 | fast_path_threshold、空闲检查、接受与退回任务 |

逻辑模块不等于必须拆四个文件，具体落点在 L7。
